# 📱 华为手机测试指南

## 方式1：Expo Go APP（最快，推荐）⭐

### 步骤

#### 1. 在华为手机上安装 Expo Go

**下载方式**：
- **华为应用市场**: 搜索 "Expo Go"
- **官网下载**: https://expo.dev/go
- **APK直接下载**: https://expo.dev/expo-go.apk

**安装后打开 Expo Go**

---

#### 2. 在电脑上启动开发服务器

```bash
cd /home/tony/.openclaw/workspace/toki-native

# 启动开发服务器
npm start
```

**等待服务器启动，会显示二维码**

---

#### 3. 手机扫码连接

**在 Expo Go 中**：
- 点击 "Scan QR Code"
- 扫描电脑屏幕上的二维码
- APP 自动加载到手机

**网络要求**：
- 手机和电脑连接同一WiFi网络
- 或使用 USB 数据线连接

---

#### 4. 测试功能

**在手机上测试**：
- 对话功能
- 记忆系统
- 语音输入
- Token计费

---

## 方式2：构建 APK 文件（独立安装）

### 步骤

#### 1. 构建 APK

```bash
cd /home/tony/.openclaw/workspace/toki-native

# 使用 Expo 构建
expo build:android

# 或使用 EAS（新版）
eas build --platform android
```

**构建时间**: 约 5-10 分钟

---

#### 2. 下载 APK

**构建完成后**：
- Expo 会提供下载链接
- 下载 APK 文件到电脑
- 文件大小约 20-30 MB

---

#### 3. 传输到华为手机

**方式**：
- USB数据线复制
- 微信/邮件发送
- 云盘上传后下载

---

#### 4. 在华为手机上安装

**华为手机设置**：
- 设置 → 安全 → 允许安装未知来源应用
- 找到 APK 文件
- 点击安装

**安装完成后打开 TOKI**

---

## 方式3：ADB 直接安装（开发者）

### 步骤

#### 1. 华为手机开启开发者模式

**设置路径**：
- 设置 → 关于手机 → 版本信息
- 连续点击"版本号" 7次
- 返回设置 → 开发者选项
- 开启 "USB调试"

---

#### 2. USB连接手机

```bash
# 检查设备连接
adb devices

# 应显示：
# List of devices attached
# XXXXXX    device
```

---

#### 3. 安装 APP

```bash
# 构建后安装
adb install app.apk

# 或直接运行
adb shell am start -n com.toknm.toki/.MainActivity
```

## 🔧 华为手机常见问题

### Q1: Expo Go 找不到？
**解决**: 
- 华为应用市场搜索 "Expo"
- 或从官网下载 APK: https://expo.dev/expo-go.apk

### Q2: 无法扫码连接？
**解决**:
- 确保手机和电脑同一WiFi
- 或使用 `npm start --tunnel`（公网隧道）

### Q3: APK 安装失败？
**解决**:
- 设置 → 安全 → 允许未知来源
- 检查 APK 文件完整性

### Q4: APP 无法打开？
**解决**:
- 检查 Android 版本（需 5.0+）
- 查看错误日志
- 重新构建 APK

## 📱 华为手机特定提示

### 网络设置
- 关闭华为 VPN/代理
- 使用稳定的 WiFi
- 避免 4G/5G 网络（可能不稳定）

### 权限设置
- 允许 Expo Go 使用相机（扫码）
- 允许麦克风（语音功能）
- 允许存储（记忆系统）

### 性能优化
- 关闭后台应用
- 清理内存
- 保持足够存储空间
