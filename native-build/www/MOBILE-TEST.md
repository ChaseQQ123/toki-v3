## ✅ 可测试的功能

### 1. 💬 智能对话
- 直接输入问题
- AI智能回复

**测试示例**：
```
你好
介绍一下自己
讲个笑话
```

---

### 2. 🤖 智能体（推荐测试）

**步骤**：
1. 点击底部"智能体"标签
2. 点击任意智能体卡片（如"数据分析师"）
3. 自动跳回"对话"标签
4. 输入问题（如："帮我分析数据"）
5. 查看智能体回复

**智能体列表**：
- 📊 数据分析师
- 💼 商务助手
- 📚 学习导师
- 🎨 设计师助手
- ✍️ 写作伙伴
- 💻 编程助手

---

### 3. 🛠️ 工具箱

**步骤**：
1. 点击"工具"标签
2. 点击任意工具
3. 输入内容
4. 点击"执行"

**工具列表**：
- 🧮 计算器（输入：2+2*5）
- 🌤️ 天气查询（输入：北京）
- 🔍 网络搜索（输入：人工智能）
- 🌐 翻译（输入：Hello）
- 📅 日期时间（直接执行）

---

### 4. 📤 文件上传

**步骤**：
1. 点击"文件"标签
2. 点击上传区域
3. 选择图片文件
4. 查看上传结果

**支持格式**：
- 图片（可直接上传）
- PDF/Word/Excel（需后端支持）

---

### 5. 🔍 网络搜索

**步骤**：
1. 点击"搜索"标签
2. 输入关键词
3. 点击"搜索"
4. 查看结果

**测试示例**：
```
人工智能最新进展
香港天气预报
Python编程教程
```

## 💡 测试技巧

```
💬 对话 | 🤖 智能体 | 🛠️ 工具 | 📤 文件 | 🔍 搜索
```

```
选择智能体 → 使用对应工具 → 查看结果
```
