# 快速生成APK - 3步完成

## 第1步：访问PWABuilder

打开浏览器，访问：
https://www.pwabuilder.com/

## 第2步：输入PWA地址

在输入框中输入：
```
https://chaseqq123.github.io/toki-v3/
```

点击 **"Start"** 按钮

## 第3步：生成APK

1. 等待分析完成（约30秒）
2. 点击 **"Android"** 标签
3. 点击 **"Download"** 按钮
4. 获得 `toki.apk` 文件

## 第4步：安装到手机

### Android手机
1. 将 `toki.apk` 传输到手机
2. 点击APK文件
3. 允许"安装未知来源应用"
4. 点击"安装"

### iPhone（需要额外步骤）
PWABuilder生成的iOS包需要：
- Mac电脑
- Xcode
- Apple开发者账号

**iPhone建议使用PWA方式：**
1. Safari打开：https://chaseqq123.github.io/toki-v3/
2. 点击"分享"按钮
3. 选择"添加到主屏幕"
4. 像APP一样使用
