## 🚀 V2.0 功能规划

### 核心功能

#### 1. 📹 视频通话（P2P）

**技术架构**：
```
用户A ↔ WebRTC ↔ 用户B
         ↕
    信令服务器（交换连接信息）
```

**实现步骤**：
1. 用户A创建房间
2. 用户B加入房间
3. 通过信令服务器交换SDP和ICE
4. 建立P2P连接
5. 实时音视频传输

**技术栈**：
- WebRTC（音视频传输）
- WebSocket（信令）
- Socket.io（实时通信）

---

#### 2. 🎬 视频生成

**功能**：文字生成视频
**模型**：CogVideoX-Flash
**流程**：
```
用户输入："一只猫在玩耍"
↓
调用智谱AI API
↓
返回视频URL
↓
播放视频
```

---

#### 3. 🎙️ 实时语音对话

**功能**：实时语音对话（像打电话）
**模型**：GLM-Realtime
**流程**：
```
用户说话 → 实时识别 → AI生成回复 → 实时播放
```

## 📝 API文档

### WebSocket消息类型

#### 客户端 → 服务器

```javascript
// 加入房间
{
  "type": "join_room",
  "room_id": "room_123"
}

// 离开房间
{
  "type": "leave_room"
}

// 发送Offer
{
  "type": "offer",
  "offer": RTCSessionDescription
}

// 发送Answer
{
  "type": "answer",
  "answer": RTCSessionDescription
}

// 发送ICE Candidate
{
  "type": "ice_candidate",
  "candidate": RTCIceCandidate
}
```

#### 服务器 → 客户端

```javascript
// 用户加入
{
  "type": "user_joined",
  "user_id": "user_abc"
}

// 用户离开
{
  "type": "user_left",
  "user_id": "user_abc"
}

// 错误消息
{
  "type": "error",
  "message": "房间已满"
}
```
